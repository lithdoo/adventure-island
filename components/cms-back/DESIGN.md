# cms-back

一张背景。地图节点 `back` 里的每一项对应一个元素，因为每张背景相对镜头的滚动不一样。

## 在树中的位置

`front=0` 的放在所有地图层之前，是远景。`front=1` 的放在传送门之后，是近景。这是 Task 023 `compose` 的两段绘制。

## 运行库交给它的数据

这些字段在 4259 张图的 `back` 项上是闭合的，没有另外的名字。每一项都是单个值，写成属性。`data` 是空对象。帧在 `Back/{bS}.img` 里，按 `ani` 选静态目录或动画目录，不放进保留数据。

| 字段 | 放在 | 用途 |
|---|---|---|
| `bS` / `no` | `attrs` | 背景图集和编号 |
| `ani` | `attrs` | 0 用静态图，非 0 用动画帧 |
| `x` / `y` | `attrs` | 锚点 |
| `rx` / `ry` | `attrs` | 视差或滚动速度 |
| `type` | `attrs` | 是否横向平铺、纵向平铺、以及是否随时间滚动 |
| `cx` / `cy` | `attrs` | 平铺步长 |
| `f` | `attrs` | 翻转 |
| `a` | `attrs` | 透明度，缺省 255 |
| `front` | `attrs` | 0 放在树的前段，1 放在后段 |

`type` 的平铺规则以合成器为准：1、3、4、6、7 横向重复，2、3、5、6、7 纵向重复。4 和 6 按 `rx` 水平滚动，5 和 7 按 `ry` 垂直滚动。

## 第一阶段

合成场景可以没有背景，也可以各放一张不滚动的远景。近景可以不出现。

## 不做什么

- 不跟随人物的游戏坐标。滚动只来自镜头和本元素的 `rx`、`ry`、`type`。
- 不承载出口或人物。
