# cms-map-layer

地图八层中的一层。节点名是 `"0"` 到 `"7"`。缺层就不创建元素。

## 画什么

这一层里的物件 `obj` 和瓦片 `tile`。合成器的排序键是：

```text
物件：(层号, 0, z, 顺序)
瓦片：(层号, 1, 瓦片 z, 顺序)
```

层号在前，所以先画完较小的层，再画下一层。同一层里物件整组在瓦片之前，组内再按 `z`。

瓦片和物件不单独做元素。一张正式地图的数量会很大，渲染树按层收束。

## 运行库交给它的数据

- 层号，0 到 7
- `info/tS`，这一层的瓦片图集
- 物件列表：图集 `oS`，路径 `l0/l1/l2`，坐标，`z`，翻转 `f`
- 瓦片列表：图块类型 `u`，编号 `no`，坐标，所在帧的 `z`

## 第一阶段

两张合成场景各自给出实际用到的层。空层不出现。占位地面可以落在其中一层，立足线仍然只是碰撞数据。

## 不做什么

- 不滚动视差。视差属于 `cms-back`。
- 不放置人物。人物在 `cms-avatar-layer`。
- 不从 WZ 路径直接读文件。
