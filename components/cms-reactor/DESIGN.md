# cms-reactor

一个可打或可点的反应堆。箱子、开关、花属于这一类。数据来自地图节点 `reactor`，不是 `obj`。

## 在树中的位置

`cms-npc` 之后、`cms-portal` 之前。Task 023 在生命体之后、传送门之前画反应堆。第一阶段不放进树。

## 运行库交给它的数据

地图节点 `reactor` 上的字段是闭合的：`id`、`x`、`y`、`reactorTime`、`f`、`name`。它们都是单个值，写成属性。`data` 是空对象。

| 字段 | 放在 | 含义 |
|---|---|---|
| `id` | `attrs` | `Reactor.wz` 里的编号，如 `0002001` |
| `x` / `y` | `attrs` | 点击和受击的位置 |
| `reactorTime` | `attrs` | 恢复或动作时间 |
| `f` | `attrs` | 朝向 |
| `name` | `attrs` | 脚本用的名字，可以为空 |
| `state` | `attrs` | 当前状态目录，默认 `"0"` |

`state` 不在地图节点上，由运行库在受击之后改。`0002001` 的目录是 `0`、`1`、`2`、`3`、`4`，画面取该目录下的画布，`origin` 对准 `x`、`y`。全库 3002 个反应堆。

物件数组里如果有 `reactor` 字段，只表示那张图跟着这个反应堆变样子。点击落点仍用反应堆自己的 `x`、`y`。物件继续留在 `cms-map-layer` 的 `objs` 里。

## 交互

人打到或点到这个坐标时，由地图运行库改变反应堆状态。这个元素显示当前状态的形象。

## 不做什么

- 不把每个物件做成反应堆。
- 第一阶段不创建这个元素。
